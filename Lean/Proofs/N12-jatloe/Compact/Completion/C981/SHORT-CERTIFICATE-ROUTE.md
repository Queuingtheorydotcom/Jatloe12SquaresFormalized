## Checkers and trust boundary

`RegionOwner` connects original real squares, arbitrary real angles,
actual containment and side bounds to the initial integer center cover.
`RegionDAG` checks each node, both children of every cut, the exact strict
complement, explicit sparse integer empty certificates, and copied output
rows. Leaf copying only weakens a region.

`RawSupportFan` verifies each cached vertex against two actual input rows.
Every queried direction must lie in their nonnegative normal cone. Every
one of the eight signed separating axes is checked against every neighbor
leaf, using the full incoming neighbor cover. The generic bridge then
turns a blocked center into genuine strict overlap of the two actual
physical squares. Equality boundaries are retained by each strict cut's
weak complement.

The external polygon algorithm, vertex enumeration, selected active rows,
and Python support tests are not trusted. Their only role is to propose
the data consumed by those Lean checkers. A missing cut child, false dual,
invalid cached basis, incomplete neighbor table, missing source plan, or
unproved convex ancestry cannot be accepted by the public contract.

All newly generated decisions use `decide +kernel`. The existing
`AngleData32.angles32_cover` native theorem is unused: the emitted owner
cover is checked independently from the32 actual root intervals.
