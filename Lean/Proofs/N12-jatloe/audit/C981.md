## Concrete symbolic simplification: positive endpoint, not target width

Let a target square have side `a>1`, center `(X,Y)` and canonical normal
`(c,s)` with `c²+s²=1`, `0<s≤c`. Let `h<1/2` satisfy

```
(c+s-1)/c < h ≤ c/(1+c).
```

Suppose `X≤t+1`, the bottom wall gives `a(c+s)/2≤Y`, and failure to own `(t,1)`
has selected the upper transverse face:

```
a/2 ≤ s(X-t)+c(1-Y).
```

This latter inequality must be derived from actual strict below/right owned
points, using the existing `PositiveFaceGeometry.upper_face_of_not_inside`;
it is not a new unproved assumption about arbitrary packings.

Define nonnegative slacks

```
E = s(X-t)+c(1-Y)-a/2,
W = Y-a(c+s)/2.
```

Since `c≥s>0` and `c²+s²=1`,

```
c(c+s) ≥ 1,     s(c+s) ≤ 1,     c+s ≥ 1,     c ≤ 1,     s < 1.
```

The exact slack identity and `X-t≤1` give

```
E+cW = s(X-t)+c - a(1+c(c+s))/2 < c+s-1 < ch.
```

Thus `W<h`. Containment also gives `Y>a/2>1/2>h`. On the row `y=h`, write

```
ell = X + [s(Y-h)-a/2]/c,
Ru  = ell+a/c,
Rv  = X + [c(h-Y)+a/2]/s.
```

The two useful exact identities are

```
sc(ell-t) = ca-c²-hs²+cE+W,
s(Rv-t-a) = E+a(1-s)-c(1-h).
```

For the first, `h(1+c)≤c` and `c≤1` imply `hs²≤c-c²`; hence its right side
is at least `c(a-1)>0`. So `ell>t` and `Ru>t+a`.
For the second, `ch>c+s-1` gives `1-s>c(1-h)`; since `a>1` and `s<1`,
its right side is strictly positive. So `Rv>t+a`.
Finally `W<h` and `s(c+s)≤1` imply `s(Y-h)<a/2`, hence `ell<X`.

We have proved

```
t < ell < X ≤ t+1 < t+a < min(Ru,Rv).
```

Both `(X,h)` and `(t+a,h)` are strict points of the square. The upper
transverse inequality is automatic for `x≥X` and `h<Y`; the other three
strict bands follow from these endpoint inequalities. This avoids imposing
a long chord on the target, which was stronger than the original selector.

For half-angle `0<z≤2/7`, setting

```
c=(1-z²)/(1+z²), s=2z/(1+z²), h=45/98
```

works because `(c+s-1)/c=2z/(1+z)≤4/9<h` and
`c/(1+c)=(1-z²)/2≥45/98`. The zero-angle case should be handled directly
from the two strict point witnesses rather than dividing by `s=0`.

Now let `m∈{2,3}`, `t=4-m`, and supply `m-1` disjoint followers whose row
sections have length greater than one and whose strict center points are
ordered after the target's strict center point. Existing interval-order
geometry puts every follower after the preceding section. The final right
endpoint exceeds `t+a+(m-1)=3+a>4`, contradicting containment.

This argument applies independently of case ID and ownership-vector labels.
The generic negative branch already has the source theorem
`C696.NegativeBoxTransfer.negative_transfer_box`, requiring explicit signed
angle and center-difference projection bounds. Together these are candidates
for one shared border-forcing API, rather than a separate proof per vector.

## Complete symbolic replacement: representative 116

The refactor subsequently found a direct two-square contradiction replacing
the entire `InitialV116.lean` certificate. Write A=(113/50,3),
C=(3,113/50), D=(2,113/50), E=(113/50,2), M=(27/10,27/10).
Any original open square of side greater than one that contains A and C
and excludes D and E contains M, for every orientation.

Choose a nonnegative frame and first suppose s≤c. The V-coordinate of D
is between the strict V-bands supplied by A and C, and its U-coordinate
is below A. Therefore D can only be excluded by the lower U-face. The
vector M−D=(7/10,11/25) has squared length 1709/2500<1, so its projection
is at most one. Since the side is strictly greater than one, M is strictly
below the upper U-face. A and C imply M's other three strict bands. The
s≥c branch is the same argument after swapping coordinates. This uses two
branches and preserves the equality case.

In representative 116, owner 6 has these four facts. Owner 3 owns
F=(12/5,3) and G=(3,12/5), and therefore their midpoint M. Actual packing
disjointness supplies the contradiction. No container premise, upper side
cap, third inside point, further outside point, finite angle cover, or
region-tree certificate is needed.

The original certificate is 109,375 bytes / 440 long lines, with 32 angle
roots. The new geometry and original-vector adapter occupy approximately
5 KB / 113 lines before replay repairs. The geometry module passed the
parent-controlled Lean replay in 1.704 seconds. The original-vector binding
requires its own acceptance receipt; this audit does not substitute the
