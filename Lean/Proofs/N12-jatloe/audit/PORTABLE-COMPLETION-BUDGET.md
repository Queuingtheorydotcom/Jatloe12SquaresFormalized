3,900 exact aliases of already existing `S12.LocalQueryData` records, each with

semantic recipe records plus repeated list/checked-list assembly. A generic

ordinary check theorems. This removes repeated scaffolding and avoids a large
combined proof accumulator; it is not a reason to combine all numerical checks
in one expensive decision. The amount saved is still unmeasured.

433,930 fewer bytes than the direct sparse bank. The generic decoder and
244-box exact-original pilot await replay. The literal kernel node count is
unchanged, so this saving does not imply fewer numerical tests.

new symbolic family exclusions or complete compact certificate objects for
