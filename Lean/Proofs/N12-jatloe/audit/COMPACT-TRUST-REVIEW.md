This is an independent source review, not a compiler run or numerical audit.
No changed packing assumption, unchecked geometric premise, admission, or
vacuous whole-case contract was found in the reviewed preferred route. The
current mathematical result remains the accepted 58-case registry and its

## Fans, cached supports, and maximum envelopes

The raw fan erases proof fields only from the numeric representation. The
semantic path retains exact equality to a certified context and actual input
row membership. The chosen lookup key need not be geometrically correct:
the selected basis still has to satisfy the cone test for the actual requested
integer direction. Missing entries reject a pair.

`DirectionalSupportCache.Datum.Check:28–33` preserves the basis denominator,
constant and strict bit exactly. Its pair check, lines 39–44, tests both actual
integer directions, including the opposite sign. `Table.Check:68–70` binds
the reference and every returned datum. Thus an arbitrary key/angle label
cannot substitute another direction without failing a checked equality.

`SupportEnvelope.Bound.Covers` allows a strict upper envelope only if every
attaining member is strict; strictly smaller members are justified by real
slack. `rectangle_sound:133–140` covers the full source/neighbor Cartesian
product. `SupportMargin.Check:24–30` uses positive denominators and an exact
cross-product identity to bind reduced margins to the original reference
radius; it also preserves the strict bit. Parent replay accepted the generic
envelope theorem in 9.626 seconds and margin bridge in 8.463 seconds.

These are generic theorems. The actual envelope groups, actual direction
equalities, every context’s support facts, and complete source/neighbor
membership still need to be instantiated and checked before replacing a
transition. The Step04 external exact audit supplies candidate data, not that
Lean instantiation. Its 284 final comparisons do not erase the 3,812 support
computations and other member/tie obligations.

`IndexedRawPairPlans.step_sound:93–126` retains complete source coverage,
complete neighbor coverage, source-block identity, unblocked neighbors,
every pair, exact complements and checked output pieces. A missing neighbor
cannot be hidden by an empty finite table: the theorem needs an index for
every pose in the original neighbor domain.

## Historical data and conditional preservation graphs

`HistoricalData` contains literal row/pose descriptions, not exclusion proofs.
Its full bank has 114,465 row IDs and 28,235 pose IDs. Rows normalize by a
positive successor denominator. `SharedPoses:55–61` looks up the actual angle
ID and ordered row list; the shared bank uses both checked 64- and 128-grids.

Sparse lookup has an explicit fallback. A missing row would become the zero
row with denominator one, and a missing pose would become angle zero with no
rows. This is not itself a proof of emptiness. The generic semantics cannot
turn either fallback into an exclusion without independently proving the
actual entrance and every subsequent transition. Nevertheless, the stronger
claim that every historical literal was preserved byte-for-byte or semantically
identically is a producer/provenance audit claim; the dictionary definitions
alone do not prove equality to the old vendor declarations. Preserve the
authenticated mapping evidence and do not call literal emission proof replay.

status bit. `knownIds` is derived from those proof entries. The remaining
condition quantifies over the complete original 117-case partition, and
`optimality` explicitly requires every remaining exclusion. No unfinished

A bounded direct-source scan of the reviewed new generic modules and the
preservation/dictionary wrappers found no `sorry`, `admit`, `axiom`,
`native_decide`, `unsafe`, `ofReduceBool`, or executable proof oracle; the one
text match was a comment saying no new axiom is used. This does not replace a
transitive compiled axiom audit. The accepted 58-case registry still inherits
the original classification’s `Lean.ofReduceBool` dependency, as already
disclosed. Its current trust model is not “standard axioms only.”

The new common-point route is a further source simplification: seven points
can cover the 434 nonfallback Step04 pairs through each square’s four own

inside both original squares, including all enclosure and boundary cases.
`CommonPoint` and its actual adapters require their own full replay before
these groups replace the corresponding pair checks. A smaller arithmetic
count is not yet a measured compilation speedup.
